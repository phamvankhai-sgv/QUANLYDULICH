Thư mục này dùng để chứa ảnh cục bộ của bạn (nếu không muốn dùng link ảnh từ internet).

Cách dùng:
1. Copy file ảnh (jpg/png) vào thư mục này, ví dụ: ha-long.jpg
2. Vào trang Admin → Quản lý Tour → Sửa tour → ô "Link ảnh tour", nhập: /img/ha-long.jpg
3. Lưu lại — ảnh sẽ hiển thị ngay trên trang chủ, danh sách tour và trang chi tiết.

Lưu ý: nếu dùng ảnh cục bộ, khi nộp bài/đóng gói dự án nhớ giữ nguyên thư mục public/img
kèm theo các file ảnh, nếu không ảnh sẽ không hiển thị trên máy khác.
